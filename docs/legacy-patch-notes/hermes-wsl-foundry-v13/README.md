# Hermes WSL Foundry v13 historical patch notes

This directory preserves the original patch-note files shipped with the historical **Hermes WSL Foundry v13.16.6** bundle.

They are retained verbatim as historical documentation. Product naming, defaults, paths, and operational guidance in these files describe the v13-era Foundry release and may have been superseded by later LatticeVale releases. For current release behavior, use the repository-root `README.md` and current guidance under `docs/`, especially `docs/Instructions.txt`, `docs/SECURITY.md`, and `docs/CHANGELOG.md`.

The current consolidated `docs/CHANGELOG.md` also retains the v13 history in LatticeVale terminology. These files are included so the original granular patch-note trail remains available for auditing and comparison.

Included source material:

- `RELEASE-NOTES-v13.md`
- `HOTFIX-v13.1.md` through `HOTFIX-v13.16.6.md`, including the historical `HOTFIX-v13.11-RC7.md`

No runtime code is loaded from this directory.
